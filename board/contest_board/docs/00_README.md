### 调试日志
- debug_log.txt - 开发过程记录

## 快速开始

1. 解压 nuttx_esp32p4_v2.tar.gz
2. 参考 docs/01_使用方法.md 编译
3. 烧录 nuttx_bin/nuttx.bin
4. 使用串口工具连接 COM6 (115200)
