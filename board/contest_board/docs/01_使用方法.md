# ESP32-P4 NuttX (OpenVela) 使用方法

## 1. 环境准备

### 1.1 工具链
- RISC-V GCC 工具链: /home/ty/toolchain/riscv64-symlinks
- esptool: Python包

### 1.2 串口连接
- COM5: USB JTAG - 烧录
- COM6: CH340 - 控制台
- 波特率: 115200

### 1.3 硬件注意
- P4 用串口烧
- C6 用下载器接 J2

## 2. 编译

    export PATH=/home/ty/toolchain/riscv64-symlinks:
    cd /home/ty/nuttx
    make -j2

## 3. 烧录

    python -m esptool --chip esp32p4 -p COM5 write-flash --force 0x2000 nuttx.bin

## 4. 常用命令

- help
- echo text
- uname -a
- uptime
- reboot
