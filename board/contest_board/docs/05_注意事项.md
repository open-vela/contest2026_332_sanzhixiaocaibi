# 注意事项

## 1. 硬件注意事项

### 1.1 串口连接
- P4 使用串口烧录 (COM5)
- C6 通信要使用下载器，单独接 C6 旁边那个 J2 下载
- 确保CH340的TX连接到GPIO38 (UART0 RX)

### 1.2 电源
- 使用稳定的5V电源
- 避免USB供电不足

### 1.3 散热
- 长时间运行注意散热
- 避免高温环境

## 2. 软件注意事项

### 2.1 BSS清零
- 必须保留nx_start.c中的BSS清零代码
- 否则系统会崩溃

### 2.2 编译环境
- 必须在WSL环境下编译
- 需要设置正确的工具链路径

### 2.3 配置文件
- 修改.config后需要重新编译
- 建议修改前备份原配置

## 3. 调试注意事项

### 3.1 串口调试
- 波特率: 115200
- 启动后需要等待12秒再发送命令
- 使用\r\n作为行结束符

### 3.2 烧录注意
- 烧录会自动重启设备
- 烧录后等待启动完成再操作

### 3.3 卡死处理
- 如果系统卡死，按复位按钮重启
- 或重新烧录固件

## 4. 安全注意事项

### 4.1 电气安全
- 测试时避免短路
- 使用合适的电压和电流

### 4.2 代码安全
- 修改前备份代码
- 测试新功能时注意监控系统状态

## 5. 常见问题

### 5.1 串口无响应
- 检查接线是否正确
- 确认波特率设置
- 尝试重新烧录

### 5.2 编译失败
- 检查工具链路径
- 确认依赖包已安装
- 查看错误日志

### 5.3 启动崩溃
- 检查BSS清零代码是否存在
- 检查配置文件是否正确
- 尝试使用默认配置
