# 改动日志

## 2026-09-14

### 1. BSS清零修复 [关键]
- 文件: sched/init/nx_start.c
- 改动: 添加BSS段显式清零
- 原因: ESP32-P4 bootloader未清零NuttX的BSS段，导致静态变量包含垃圾值
- 影响: 修复了启动崩溃、group结构体初始化失败、任务列表损坏等问题

### 2. group_create.c 初始化逻辑 [保留]
- 文件: sched/group/group_create.c
- 改动: 在group_initialize()中添加memset清零
- 原因: 确保group结构体在使用前被正确初始化
- 状态: 已保留，配合BSS清零共同工作

### 3. 调试代码清理 [完成]
- 清理了所有临时添加的ets_printf调试代码
- 清理了task_init.c、task_setup.c、task_spawn.c、env_dup.c中的调试代码

### 4. NSH配置 [已修改]
- 添加: CONFIG_SYSTEM_NSH_DEVMEM=y
- 用途: 支持devmem命令读取硬件寄存器

## 修改的文件列表

1. sched/init/nx_start.c - BSS清零
2. sched/group/group_create.c - group初始化
3. .config - 添加devmem支持
